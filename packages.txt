# Package list for the CachyOS + SwayFX desktop stack (see ../CLAUDE.md).
# Installed with: sudo pacman -S --needed - < packages.txt   (official repos)
#                 yay -S --needed <pkg>                       (AUR — see AUR_PACKAGES below)
#
# One line per package. Comments (#) and blank lines are ignored by setup.sh.
# Regenerated 2026-09-06 against `pacman -Qqen`/`pacman -Qqem` to close drift
# that had accumulated since the initial 2026-09-05 commit — this file had
# stopped tracking most packages installed over the course of the Sway build-out.

# --- Compositor / session ---
# swayfx is AUR (see AUR_PACKAGES in bootstrap.sh), not installed from here.
# It's the official `cachyos`-repo binary (not the AUR `swayfx-git` this
# used to be), but plain pacman can't install it on its own: it depends on
# wlroots0.19, which has no prebuilt package anywhere, so yay is still
# needed to resolve+build that one AUR dependency. A `chaotic-aur/swayfx`
# build exists that needs zero building at all (depends on wlroots0.20
# instead), but chaotic-aur is NOT a repo this box configures anywhere --
# found 2026-09-08 the hard way, blocking an entire fresh VM install with
# `error: database not found: chaotic-aur`. Don't reach for it again
# without actually adding real repo setup (Server=/keyring steps) to
# bootstrap.sh first.
swaybg
swayidle
# swaylock itself isn't the active lock command (see lockscreen/lock.sh --
# rustlock, built from source by bootstrap.sh, is) -- kept installed as a
# trivial, always-available fallback if rustlock ever misbehaves.
swaylock
greetd
greetd-agreety
greetd-regreet
cage
# uwsm: what sway-uwsm.desktop's Exec actually invokes -- without this,
# the only remaining session entry (see bootstrap.sh's sway.desktop.disabled
# step) fails at the greeter with "uwsm not found" and login is impossible.
# Found 2026-09-07 completely missing on the VM; on the dev machine it turned out to
# be an orphaned transitive dependency (`pacman -Qi uwsm` shows "Required
# By: None" despite "Install Reason: dependency") -- nothing here ever
# actually depended on it explicitly, so it was never guaranteed by a
# fresh bootstrap.sh run either.
uwsm
# autotiling: sway has no built-in dwindle-style auto split (Hyprland does);
# this reproduces it over sway's IPC -- see sway/config's `exec autotiling`.
autotiling

# adw-gtk-theme: the actual adw-gtk3/adw-gtk3-dark GTK3 themes the
# theming pipeline's light/dark mode picks between (theming/apply-theme.py's
# MODE_DEFAULTS) -- found missing from this file 2026-09-07 despite being
# load-bearing for every palette's GTK3 rendering, light or dark; only
# "worked" because it happened to already be installed.
adw-gtk-theme
# ttf-jetbrains-mono-nerd / ttf-cascadia-mono-nerd / ttf-cascadia-code-nerd:
# the actual fonts sway/config (bar), ghostty/config (font-family =
# "CaskaydiaMono Nerd Font", an exact match to ttf-cascadia-mono-nerd's
# family name), and waybar/walker all reference. Found 2026-09-07
# completely missing here -- the dev machine only had them via a manual
# ~/.local/share/fonts install (home-directory-only, invisible to any
# script), and the VM had neither that nor these packages at all, which
# produced ghostty's font-fallback silently rendering at a much larger
# cell size than intended -- surfaced as btop refusing to run ("terminal
# too small") in a window that was actually plenty big in pixels.
ttf-jetbrains-mono-nerd
ttf-cascadia-mono-nerd
ttf-cascadia-code-nerd
fastfetch
# chromium: tracked here specifically (unlike firefox/discord/etc., which
# are deliberately NOT tracked -- personal app choices, see the note near
# the bottom of this file) because theming/apply-theme.py retints
# its toolbar/tab color on every theme switch via Chromium's managed
# enterprise-policy mechanism (--refresh-platform-policy, upstream since
# Chrome ~142 -- the plain official package works, no fork/AUR needed).
chromium
# imagemagick: generates the color-swatch preview PNGs for the walker/
# elephant theme picker (theming/generate-previews.py). Not otherwise
# a hard dependency of the theming system itself.
imagemagick
